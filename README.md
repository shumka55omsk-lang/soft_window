# Калькулятор мягких окон для Vercel

## Что изменено

- Добавлены две высоты: `Высота 1` и `Высота 2`.
- Для проёмов с наклоном чертёж строится как трапеция.
- Площадь считается по большей высоте: `ширина × max(высота 1, высота 2)`.
- Окантовка выделяется коричневым.
- Молния отображается с двух сторон на указанном отступе от края окантовки.
- Если галочка `Молния` выключена, молния не считается и не рисуется.
- PDF отправляется в Telegram через серверную функцию Vercel `/api/send-telegram`, токен не хранится в HTML.

## Файлы

- `public/index.html` — калькулятор.
- `api/send-telegram.js` — серверная функция для Telegram.
- `.env.example` — пример переменных окружения.
- `vercel.json` — настройки проекта.

## Переменные окружения в Vercel

В Project → Settings → Environment Variables добавьте:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
```

После добавления переменных сделайте новый Deploy.

## Проверка API

После деплоя откройте:

```text
https://ВАШ-ДОМЕН.vercel.app/api/send-telegram
```

Должно показать, настроены ли переменные.
